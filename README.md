# Raj Tripathi - Portfolio

Personal portfolio for Raj Tripathi, an entry-level Data Analyst.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository named `RajTripathi7879.github.io`.
2. Upload `index.html` and `style.css`.
3. Upload your resume as `Raj_Tripathi_Resume.pdf`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then **Save**.
7. Your site will be available at `https://RajTripathi7879.github.io/`.

## Important
The portfolio links are based on the resume. Replace any project links with the exact repository URLs if your repositories use different names.
